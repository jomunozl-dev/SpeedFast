# SpeedFast - Sistema de Gestión de Entregas

Proyecto desarrollado en Java para la asignatura **Fundamentos de Programación Orientada a Objetos II**.

La aplicación permite gestionar **repartidores, pedidos y entregas** mediante una interfaz gráfica desarrollada con Java Swing y persistencia de datos mediante JDBC.

---

## Tecnologías utilizadas

- Java JDK 25
- Apache NetBeans IDE 29
- Maven
- Java Swing
- JDBC
- Oracle Autonomous Database (Oracle Cloud)
- Oracle SQL Developer
- Oracle Wallet
- GitHub

> El proyecto fue desarrollado en Apache NetBeans, pero al utilizar Maven también puede abrirse y ejecutarse desde IntelliJ IDEA.

# 4. Funcionalidades

## Gestión de Repartidores

Permite realizar las siguientes operaciones:

- Registrar repartidores.
- Listar repartidores.
- Editar repartidores.
- Eliminar repartidores.

## Gestión de Pedidos

Permite:

- Registrar pedidos.
- Listar pedidos.
- Editar pedidos.
- Eliminar pedidos.

Tipos disponibles:

```text
COMIDA
ENCOMIENDA
EXPRESS
```

Estados disponibles:

```text
PENDIENTE
EN_REPARTO
ENTREGADO
```

## Gestión de Entregas

Permite:

- Registrar entregas.
- Asociar una entrega a un pedido.
- Asociar una entrega a un repartidor.
- Registrar fecha y hora.
- Listar entregas.
- Editar entregas.
- Eliminar entregas.

Los pedidos y repartidores son obtenidos desde la base de datos y mostrados mediante `JComboBox`.

# 6. Base de datos

El proyecto utiliza:

**Oracle Autonomous Database (Oracle Cloud)**

La actividad entrega originalmente un esquema de base de datos utilizando sintaxis MySQL.

Para este proyecto se realizó una adaptación del esquema a Oracle, manteniendo las entidades y relaciones solicitadas.

Las tablas utilizadas son:

```text
REPARTIDORES
PEDIDOS
ENTREGAS
```

La relación principal es:

```text
PEDIDOS
   ↑
   │ id_pedido
   │
ENTREGAS
   │
   │ id_repartidor
   ↓
REPARTIDORES
```

# 7. Script SQL para Oracle

Antes de ejecutar la aplicación se deben crear las tablas necesarias.

El script puede ejecutarse desde **Oracle SQL Developer**.

También se encuentra disponible en:

```text
database/speedfast_oracle.sql
```

```sql
-- =============================================
-- SPEEDFAST
-- SCRIPT BASE DE DATOS ORACLE
-- =============================================


-- =============================================
-- TABLA REPARTIDORES
-- =============================================

CREATE TABLE repartidores (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nombre VARCHAR2(100) NOT NULL
);


-- =============================================
-- TABLA PEDIDOS
-- =============================================

CREATE TABLE pedidos (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    direccion VARCHAR2(100) NOT NULL,
    tipo VARCHAR2(20),
    estado VARCHAR2(20),

    CONSTRAINT chk_pedidos_tipo
        CHECK (
            tipo IN (
                'COMIDA',
                'ENCOMIENDA',
                'EXPRESS'
            )
        ),

    CONSTRAINT chk_pedidos_estado
        CHECK (
            estado IN (
                'PENDIENTE',
                'EN_REPARTO',
                'ENTREGADO'
            )
        )
);


-- =============================================
-- TABLA ENTREGAS
-- =============================================

CREATE TABLE entregas (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    id_pedido NUMBER,
    id_repartidor NUMBER,
    fecha DATE,
    hora VARCHAR2(8),

    CONSTRAINT fk_entregas_pedido
        FOREIGN KEY (id_pedido)
        REFERENCES pedidos(id),

    CONSTRAINT fk_entregas_repartidor
        FOREIGN KEY (id_repartidor)
        REFERENCES repartidores(id)
);
```

# 8. Formato de fecha y hora

La fecha se registra desde la aplicación utilizando:

```text
AAAA-MM-DD
```

Ejemplo:

```text
2026-10-05
```

La hora puede ingresarse desde la interfaz como:

```text
HH:MM
```

Ejemplo:

```text
20:30
```

La aplicación almacena la hora en Oracle utilizando el formato:

```text
HH:mm:ss
```

Ejemplo:

```text
20:30:00
```

Por esta razón la columna `HORA` está definida como:

```sql
hora VARCHAR2(8)
```
